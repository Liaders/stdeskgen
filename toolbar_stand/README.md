# Стенд панели StatusDesk

Запуск: `start-toolbar-stand.cmd` в каталоге rdgen. Нужны Flutter 3.24.5 и Visual Studio 2022 с разработкой классических приложений на C++.

Перед запуском prepare.ps1 копирует актуальную оболочку из customization/compact_session_toolbar.dart. Геометрия оболочки, язычок, кнопка организации и счётчик дисплеев используются из клиента. Копию lib/models/rdgen_compact_session_toolbar.dart вручную не редактировать: изменения оболочки делаются в customization, затем повторно выполняется prepare.ps1.

Кнопки мыши, клавиатуры, настройки, запись, чат и завершение — демонстрационные. Они не воспроизводят полностью меню RustDesk. Выбор организации не обращается к API, не проверяет права и не сохраняется. Стенд не управляет удалёнными компьютерами и не читает конфигурацию StatusDesk.

В правой части можно менять состояния, организацию, мониторы, фон и запись. Настройки скрываются кнопкой сверху. Размер области сеанса меняется вместе с окном. При узком окне действия панели прокручиваются горизонтально.

В консоли flutter run: r — hot reload после правок main.dart; R — полный перезапуск; q — выход. После изменения customization сначала выполните prepare.ps1, затем r. Сборка настоящего клиента для визуальной проверки оболочки не требуется; совместимость с RustDesk и реальные действия по-прежнему проверяются отдельно.

Проверка: flutter analyze и flutter test из toolbar_stand (после prepare.ps1). Сборка: flutter build windows --debug. Самостоятельно запускаемый стенд находится в build/windows/x64/runner/Debug; переносить весь каталог, не один EXE.

Запуск автоматически назначает папке временную свободную букву диска (обычно Z:), чтобы компилятор шейдеров Flutter 3.24.5 не ошибался на кириллице в пути. При выходе назначение снимается. Для проверочной сборки без открытия окна: powershell -NoProfile -ExecutionPolicy Bypass -File toolbar_stand/start.ps1 -BuildOnly. Консоль со стендом следует закрывать через q, чтобы выполнилась очистка назначения.


Выпадающие меню содержат демонстрационные пункты панели: мониторы, режим окна, изображение (включая вложенные качество/кодек/разрешение), клавиатура и мышь, действия, организация, чат и запись. Переключатели и радиопункты меняют только память стенда; команды показывают результат в нижней строке. Реальный клиент ограничивает состав меню платформой, возможностями узла и правами; стенд не воспроизводит серверную авторизацию. Подтверждённая организация в меню сеанса не переназначается; произвольные состояния задаются справа для тестирования.


Обновлённый сценарий организаций: над разделителем отображаются привязки устройства с галочкой текущего сеанса; ниже — только Назначить организацию. Поиск фильтрует список без учёта регистра. Создание предварительно отмечает демонстрационную группу оператора Статус и автоматически выбирает новую организацию. При уже назначенной организации появляется подтверждение переподключения; отмена оставляет текущий сеанс, подтверждение увеличивает демонстрационный номер сеанса. В правой панели можно проверить устройство без организаций. Все созданные записи исчезают после перезапуска стенда. Строки меню имеют высоту 28 px, шрифт Roboto 13, начертание 400.


Первое назначение: если привязок нет, кнопка организации сразу открывает окно назначения. При отсутствии псевдонима в этом окне предлагается необязательный псевдоним для поиска и навигации; имя компьютера не меняется. Псевдоним сохраняется в памяти стенда после выбора или создания организации, отмена отбрасывает черновик. Для демонстрации используйте переключатели Устройство без организаций и Псевдоним уже задан.


Назначение теперь всегда требует подтверждения, включая первое назначение и Создать и назначить. Привязка устройства добавляется только после подтверждения. Создать добавляет запись в справочник без привязки, смены сеанса или сохранения черновика псевдонима. Если организация уже создана, отмена её назначения не удаляет созданную запись. При назначенной организации и отсутствии псевдонима контекстное меню предлагает отдельное Назначить псевдоним устройства; после сохранения пункт скрывается.
