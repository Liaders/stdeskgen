# Стенд панели StatusDesk

Запуск: start-toolbar-stand.cmd в каталоге rdgen. Нужны установленные Flutter 3.24.5, Python и Visual Studio 2022 с компонентами C++.

Перед запуском prepare.ps1 и prepare_stand.py копируют актуальную оболочку из customization/compact_session_toolbar.dart. Темы, размеры, пульсация, кнопка организации и счётчик дисплеев берутся из клиента. Производственный файл не меняется. Генерируемую копию lib/models/rdgen_compact_session_toolbar.dart вручную не редактировать.

Кнопки идут как в текущей панели: закрепление, мониторы, полноэкранный режим, изображение, клавиатура, действия, разделитель, организация, «Ещё», завершение. В «Ещё» — значки чата/голосового вызова и записи. Одиночные кнопки имеют размер 30×30, подсветка прямоугольная с радиусом 4. При одном мониторе счётчик скрыт.

## SVG-иконки

Набор находится в assets/icons/: SVG с прозрачным фоном, сеткой 20×20, единым контуром 1,5 и цветом, задаваемым темой. Flutter отображает их через закреплённый flutter_svg 2.0.10+1. Переключатель «Новые SVG-иконки» справа включает новый набор или исходную рисовалку клиента для сравнения. Масштаб Windows меняется в настройках экрана; проверки стенда также покрывают 100%, 125% и 150%.

«Тёмная тема сеанса» меняет фон и панель вместе. Цвет закреплённой булавки — оранжевый, крестик белый на красном. Иконки можно менять по одному в SVG-файлах. В консоли flutter run: r — hot reload, R — полный перезапуск, q — выход. После правки assets иногда нужен полный перезапуск.

## Демонстрационные действия

Меню и действия не управляют настоящими сеансами. Нет подключения к серверу, чтения токенов или конфигурации установленного StatusDesk. В диалоге «Выберите организацию» привязки показываются над поиском, новые варианты — в выпадающем списке. Создание организаций отсутствует. Псевдоним доступен для повторного редактирования. Смена организации предлагает переподключение. Данные существуют только в памяти стенда. Сетевые задержки и проверки прав здесь не воспроизводятся.

## Проверки и сборка

Из toolbar_stand: flutter analyze, flutter test (после prepare.ps1).

Сборка без открытия приложения из rdgen:

    powershell -NoProfile -ExecutionPolicy Bypass -File toolbar_stand/start.ps1 -BuildOnly

Скрипт временно назначает свободную букву диска, чтобы Flutter 3.24.5 корректно собирал шейдеры при кириллице в пути. После завершения назначение снимается. Для переносимого стенда нужен весь каталог toolbar_stand/build/windows/x64/runner/Debug, не только EXE.

SVG пока применены только к стенду. Перенос в настоящий клиент выполняется отдельно после визуального выбора.
