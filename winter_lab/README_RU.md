# Новый зимний стенд

Запуск: `start-winter-lab.cmd` в корне rdgen. Первая команда создаст стандартный
Windows runner Flutter. Затем запускается release-режим. Сборку запускает пользователь.
Для получения EXE: `powershell -File winter_lab/start.ps1 -BuildOnly`.

Новый движок, без кода прежней анимации. Из старых файлов взят только исходный
обычный логотип компании. Старый стенд не изменён.

Режимы: пустой интерфейс / статичное оформление / только снег / всё вместе.
Статичный сугроб пока диагностический, финальные PNG и оформление не добавлены.
Снег: 16/24/32 частицы, без физики и накоплений. Активное окно — до 60 FPS,
неактивное — до 30, скрытое — остановка. Фактическая частота зависит от дисплея.
Фоновый тикер получает vsync, но обновляет и перерисовывает слой только 30 раз/с.
Слой снега изолирован RepaintBoundary; массивы выделяются при создании.

Сравнивать режимы в диспетчере задач после 20 секунд стабилизации: CPU и GPU.
Одинаковый размер окна, без других нагрузок; 3 замера каждого режима.
Записать процессор, видеокарту, масштаб Windows и частоту монитора.
На первом запуске отдельно проверить отсутствие нагрузки после сворачивания
и переключение 60/30 при потере фокуса на конкретной версии Windows.
Нулевую нагрузку заранее не обещаем: CPU/GPU нужно измерить на целевом компьютере.

Диагностика: сравнить пустой интерфейс, кадры без рисования при 60 и 30,
затем только снег при 60 и 30 (16 частиц). Режим без рисования сохраняет
тот же vsync и перерисовку пустого CustomPainter, но исключает движение и
команды Canvas. Это не отдельный тест отправки готовых кадров GPU: Flutter
может оптимизировать пустой слой. На мониторе 60 Гц ticker по-прежнему
просыпается до 60 раз/с; ограничитель 30 снижает только частоту полезных обновлений.

Переключатель Ticker / Таймер позволяет сравнить механизмы при 30/60 FPS.
В режиме таймера Ticker остановлен: периодический Timer запрашивает обновления,
а Stopwatch измеряет фактическое время движения. Таймер может давать менее
равномерную подачу кадров; уменьшение CPU на 60 FPS не гарантируется.
Сравнивать при активном окне одинакового размера и одинаковом режиме рисования.

Дополнительная диагностика:
- «Только таймер»: пробуждения Timer без движения, notifyListeners и перерисовки.
- «Кадры без рисования»: уведомления перерисовки пустого слоя.
- «Только снег»: тот же слой с движением и рисованием.
Переключатели изоляции слоя и обрезки позволяют сравнить их цену отдельно.
График UI/Raster выключить при итоговом измерении CPU.

Для DevTools запустить start-winter-lab-profile.cmd в корне rdgen.
Открыть адрес DevTools из терминала; в Performance записать каждый режим,
проверить Track Widget Builds / Track Layouts / Track Paints. Эти средства
сами добавляют нагрузку: итоговые проценты снова измерять в release.
