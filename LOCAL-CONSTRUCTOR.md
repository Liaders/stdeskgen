

### Версии клиента и профиль по умолчанию

Базовая версия выбирает исходный тег RustDesk (1.5.0 или 1.5.1). Версия нашего клиента имеет четвёртый компонент: 1.5.0.1, 1.5.0.2 или 1.5.1.1. Пустой «Номер нашей сборки» резервирует следующий номер; явный номер должен быть больше уже зарезервированного для этой базы. Неудачные попытки также занимают номер. Счётчики хранятся локально в `.local-version-counters.json`: сохраняйте этот файл при переносе конструктора. Все платформы используют общий счётчик для выбранной базы. Номер включён в имя установщика, сведения о версии и библиотеку публикации. Версия Cargo/сетевого протокола остаётся исходной трёхкомпонентной.

При открытии страницы автоматически читается `default-config.json` в каталоге rdgen. Если его нет, создаётся начальный профиль. Кнопка «Сохранить как конфигурацию по умолчанию» заменяет его текущими настройками. Файл может содержать пароль и настройки сервера; он исключён из Git, как и счётчики. Существующий профиль при запуске не перезаписывается.

Windows x86 сохраняет исходное оформление Sciter: цвета, панели, вкладки и изображения Flutter к нему не применяются, пользовательские изображения и выбор темы игнорируются. Настройки подключения и разрешений сохраняются.

RustDesk 1.5.1 доступен для сборки и ручной публикации. Собственный канал автоматического обновления пока поддерживает только базу 1.5.0: в 1.5.1 изменён штатный механизм проверки обновлений, его адаптация требует отдельной работы. Выпущенные установщики не меняются после обновления конструктора: нужно собрать и опубликовать новый клиент.
