

### Версии клиента и профиль по умолчанию

Базовая версия выбирает исходный тег RustDesk (1.5.0 или 1.5.1). Номер принадлежит выпуску: Windows x64/x86, Linux и macOS собираются с одной версией, например 1.5.0.3. Поле «Текущий выпуск» показывает выбранный номер. Повторная попытка и сборка другой платформы его не увеличивают. Кнопка «Создать следующий выпуск» переключает конструктор на следующий номер для выбранной базы. Нажимайте её при изменении функционала или конфигурации выпуска. Каждая база имеет свой текущий выпуск; выбор сохраняется между перезапусками в `.local-version-counters.json`. Сохраняйте этот файл при переносе конструктора. Старые числовые счётчики автоматически становятся текущими выпусками без обнуления. Уже опубликованный файл той же платформы и ревизии не заменяется: для изменённого установщика создайте следующий выпуск. Номер включён в имя установщика, сведения о версии и библиотеку публикации. Версия Cargo/сетевого протокола остаётся исходной трёхкомпонентной.

При открытии страницы автоматически читается `default-config.json` в каталоге rdgen. Если его нет, создаётся начальный профиль. Кнопка «Сохранить как конфигурацию по умолчанию» заменяет его текущими настройками. Файл может содержать пароль и настройки сервера; он исключён из Git, как и счётчики. Существующий профиль при запуске не перезаписывается.

Windows x86 сохраняет исходное оформление Sciter: цвета, панели, вкладки и изображения Flutter к нему не применяются, пользовательские изображения и выбор темы игнорируются. Настройки подключения и разрешений сохраняются.

Наш независимый канал автообновлений поддерживает установленные Windows x64/x86 EXE-клиенты на базе RustDesk 1.5.0 и 1.5.1. Конструктор включает канал отдельной кнопкой; публикация с receipt обновляет страницу и metadata одним установщиком. Сборки без настройки канала сохраняют штатный путь. Уже выпущенные установщики не меняются после обновления конструктора: нужно собрать и опубликовать новый клиент. Linux/macOS пока скачиваются вручную.


### Автообновление по умолчанию

Флажок «Включить автоматическое обновление клиента» включён по умолчанию для устанавливаемых Windows x64/x86 клиентов на поддерживаемой базе с входящими подключениями. Адрес desk.status16.ru/client/ и stable подставляются автоматически. Старые профили без нового поля также получают это значение; явное отключение сохраняется при экспорте и в default-config.json. Снятый флажок исключает наш канал и задаёт запрет автоматических обновлений в конфигурации клиента. Linux/macOS, режим без установки и только исходящие подключения не поддерживаются. Сборка ничего не публикует: публикация в рабочий канал выполняется отдельным действием.
