# Android StatusDesk

## Создание APK

1. Перезапустите локальный конструктор после его обновления.
2. Выберите Android, базовую версию RustDesk и архитектуру. Для большинства современных телефонов подходит ARM64; ARMv7 предназначена для старых 32-битных устройств, x86_64 — преимущественно для эмуляторов. Можно собрать все три варианта.
3. Проверьте сервер, ключ, API, иконку и логотип. Нажмите «Собрать клиент» и подтвердите создание.
4. Оставьте конструктор запущенным: после успешной сборки APK автоматически скачивается в downloads/<идентификатор сборки>/ и подписывается на этом компьютере. Итоговый файл виден в локальном каталоге на вкладке «Публикация».

Пакет по умолчанию: ru.status16.statusdesk. Он устанавливается отдельно от оригинального RustDesk. Номер версии общий с остальными платформами, например 1.5.1.2. Не меняйте идентификатор пакета для обновления уже установленного приложения. Изменения панелей и вкладок настольного клиента на Android не переносятся.

## Постоянный ключ Android

Android требует подпись каждого APK. Для установки следующего выпуска поверх предыдущего необходим тот же ключ. GitHub собирает неподписанный APK; ключ остаётся локально в .local-android-signing/, пароль защищён Windows DPAPI текущего пользователя. Это обязательная подпись Android-приложения, отдельный механизм ключей автообновления RustDesk не добавляется.

На вкладке «Публикация» есть кнопка резервной копии Android-ключа. Полученный ZIP содержит закрытый ключ и пароль: храните его отдельно в защищённом месте. Не отправляйте в GitHub и не размещайте рядом с дистрибутивами. При потере ключа обновить приложение поверх существующей установки не получится.

Восстановление на другом Windows-компьютере под пользователем, запускающим конструктор, из каталога rdgen:

```powershell
.\.venv\Scripts\python.exe -m rdgenerator.android_signing restore "D:\Backup\android-signing-backup.zip"
```

Существующий другой ключ автоматически не заменяется.

## Проверка и публикация

При сборке проверяются встроенные настройки сервера, пакет, версия, нативная библиотека, изображения; при скачивании — подпись и сертификат. Работу подключения, разрешений захвата экрана и управления нужно дополнительно проверить на Android-устройстве.

Публикация Android на странице загрузок пока отключена. Автоматическая установка обновлений Android не реализована. Скачанный подписанный APK можно передать для ручной проверки; перед установкой обновления сохраняйте тот же пакет и ключ.
