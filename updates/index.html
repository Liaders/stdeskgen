Программа удалённого доступа

Выберите вашу операционную систему и скачайте приложение для подключения к компьютерам.

Windows

Разрядность указана в настройках Windows: «Система» → «О системе» → «Тип системы». Для 64-разрядной Windows выберите 64 бита, для 32-разрядной — 32 бита.

Windows · 64 бита
Пока недоступно
Windows · 32 бита
Пока недоступно

macOS

Тип процессора указан в меню Apple → «Об этом Mac». Для процессоров M1 и новее выберите Apple Silicon, для процессоров Intel — Intel.

Apple Silicon · 64 бита
Пока недоступно
Intel · 64 бита
Пока недоступно

Linux

Откройте терминал и выполните uname -m. Для x86_64 выберите Intel / AMD, для aarch64 или arm64 — ARM64.

Intel / AMD · 64 бита
Пока недоступно
ARM64 · 64 бита
Пока недоступно

Android

Скачайте APK и откройте его на устройстве. Если Android запросит разрешение на установку из этого источника, разрешите её. Новые версии устанавливаются вручную поверх приложения.

Пока недоступно

Как начать

Скачайте и запустите приложение. Для доступа к устройствам организации войдите в свою учётную запись.

Если не знаете, какой вариант выбрать, уточните у вашего системного администратора.
