# Меню устройств, организации и курсор без мыши

Область: Flutter desktop (Windows x64, Linux, macOS). Android и Sciter x32 не меняются. SVG из стенда не переносятся.

В окне выбора организации «Сохранить» подтверждает только привязку устройства через существующий серверный API, обновляет назначенные организации и оставляет окно открытым. «Подключиться» выбирает организацию сеанса; внутри уже назначенного сеанса действует существующий механизм переподключения. Завершение сеанса сохраняет отдельное действие «Сохранить и завершить».

В меню вкладки «Организации»: Подключиться → Добавить организацию → Копировать ID. В остальных меню копирование следует сразу за подключением. Серверный псевдоним изменяется по существующему API с проверкой прав; локальные значения не переносятся и на desktop не используются. До получения серверных данных показывается имя компьютера. Подпись устройств в организациях, коллегах, доступных устройствах и адресной книге содержит ID.

В Slim UI убран только заголовок нового соединения. Статус готовности называется «Подключено». В панели сеанса значок организации использует акцент, активная запись отмечается красным в кнопках записи и «Ещё». После «Ещё» добавлено сворачивание с обычным размером кнопки.

## Windows без физической мыши

`headless_cursor.rs` вызывается только из службы передачи курсора. При недоступной форме курсора и отрицательном `SM_MOUSEPRESENT` один раз за период активных подписчиков проверяется Mouse Keys. Если режим выключен и автоматика разрешена, сохраняются все исходные поля MOUSEKEYS, затем временно включается только MKF_MOUSEKEYSON. Настройка не записывается в профиль Windows (SPIF_UPDATEINIFILE не используется).

При сбросе службы после последнего подписчика восстанавливаются исходные поля, только если текущие поля всё ещё совпадают с установленными нами. Режим, ранее включённый пользователем, не меняется. Журнал рядом с конфигурацией позволяет восстановить временное изменение после аварии при следующей активации службы курсора. После принудительного завершения процесса мгновенное восстановление невозможно. При обычной перезагрузке временная настройка Windows не должна сохраняться.

Переключатель «Автоматически исправлять курсор на компьютерах без мыши» находится в настройках принимающего Windows; ключ `rdgen-auto-headless-cursor=N` отключает исправление для последующих активаций. Виртуальная HID-мышь может считаться присутствующей: тогда коррекция намеренно не срабатывает. Отсутствие формы при наличии мыши не является основанием менять системные настройки.

Ручная проверка на Server 2016 обязательна: отсутствие мыши и нормальный курсор после подключения; два одновременных оператора; восстановление после последнего отключения; сохранение изначально включённого режима; ручное изменение настройки во время сеанса; аварийное завершение и повторный запуск.

## Поверхность изменений

- `peer_card.dart`: названия/подписи и меню; исходные действия подключения и паролей сохраняются.
- `common.dart`: поиск по серверному отображаемому имени вместо устаревшего локального псевдонима на desktop.
- `group_model.dart` / модуль разрешения имён: прекращено чтение локальных псевдонимов на desktop; Android сохраняет старый путь.
- копия `rdgen_organizations.dart`: маркер вкладки для особого порядка меню.
- `connection_page.dart` / `rdgen_slim_ui.dart`: заголовок и статус, без изменения боковой панели и поля ID.
- `remote_toolbar.dart`: отображение записи и действие сворачивания; штатные действия записи/чата сохраняются.
- общий `rdgen_organization_editor.dart`: независимое сохранение привязки.
- `rdgen_organization_store.dart` / `desktop_home_page.dart`: обновление существующего кэша серверных имён и перерисовка вкладок после явного изменения псевдонима.
- Windows `platform/mod.rs`, `server/input_service.rs`: регистрация модуля и тонкие хуки состояния службы курсора. На других ОС обработка курсора остаётся исходной.
- `desktop_setting_page.dart`: переключатель коррекции только для Windows.

Автоматические проверки: существующие тесты на RustDesk 1.5.1, тест сохранения привязки без запуска сеанса, Flutter-анализатор и отдельная компиляция Windows-адаптера против WinAPI. Последняя проверяет типы, но не заменяет живой тест на Server 2016.
