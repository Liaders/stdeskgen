# Панель сеанса и стенд

Современные настольные клиенты используют компактную панель при доступном серверном API учёта организаций. Windows x32 и Android этим переносом не меняются. На неподдерживаемом сервере сохраняется штатная панель.

Панель: высота кнопок 30 px, скругление 4 px, равномерные промежутки, контурные значки, отдельный разделитель перед организацией. Счётчик дисплеев скрыт при одном дисплее; при нескольких есть стрелка выбора. Неназначенная организация мягко пульсирует с полным циклом 1,8 секунды. Системное отключение анимации учитывается. Меню имеют строки 28 px и обычный шрифт 13 px.

Кнопки управления используют настоящие виджеты RustDesk и сохраняют проверки прав и возможностей удалённого узла. Чат, вызов и запись находятся в «Ещё».

Меню организации показывает привязки устройства и отмечает организацию текущего сеанса. Без привязок открывается окно назначения. Доступны поиск, создание без назначения и создание с последующим подтверждением назначения. Псевдоним при первом назначении предлагается только если сервер подтвердил отсутствие значения и право записи; отдельно пункт доступен при назначенной организации. При ошибке API клиент не подменяет серверный псевдоним локальным.

Подтверждённая организация текущего сеанса неизменна. Смена запускает новое окно с новой native-сессией, без connToken старого сеанса; старое окно закрывается только после успешного создания нового. Нужная новая привязка устройства записывается до нового подключения, с подтверждения пользователя. При ошибке подключения подтверждённая привязка остаётся, организация нового сеанса не считается сохранённой без ответа сервера. Сначала закройте другие окна дисплеев того же сеанса: переключение при оставшихся окнах недоступно.

Серверные требования: API v2 session-work-groups и отдельные GET/PUT /api/statusdesk/devices/{rustdesk_id}/alias. Контракт согласован с серверным чатом; его код и развёртывание выполняются отдельно. На старом сервере псевдоним не редактируется. Старые подтверждённые сеансы не переписываются.

Напоминание при завершении сеанса без организации сохранено: сохранить и завершить, завершить без организации, вернуться в сеанс.

Локальный стенд: start-toolbar-stand.cmd. В нём действия демонстрационные; конфигурация и сервер не затрагиваются. Геометрия оболочки и значки копируются из клиентского модуля при запуске.

Проверки: тесты протокола и прав API, widget-тесты клиента и стенда, применение адаптеров к 1.5.0 и 1.5.1, сравнение полного анализатора desktop до/после. Реальные сетевые сеансы и системные меню требуют проверки собранным клиентом отдельно.
