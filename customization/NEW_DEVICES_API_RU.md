# Дата регистрации устройства для вкладки «Новые»

Серверные изменения и развёртывание выполняются отдельно.

В существующий ответ `GET /api/peers` добавить поле `created_at` для каждой
записи на всех страницах. Источник — `devices.created_at`, первоначальная дата
регистрации устройства в CortenDesk. Формат ISO 8601 с часовым поясом,
предпочтительно UTC: `"2026-11-25T09:15:00Z"`. Неизвестная дата — `null`.

Не менять авторизацию, фильтрацию доступных устройств, пагинацию и остальные
поля ответа. Не использовать дату активности, обновления записи, назначения
организации или первого обнаружения устройства конкретным клиентом.

Клиент отбирает устройства младше 24 часов, сортирует по убыванию даты,
показывает относительное время и счётчик. Без корректной даты устройство не
попадает во вкладку. Дополнительный endpoint и отдельные запросы дат не нужны.

Проверить ответ для обычного оператора и администратора; недоступные устройства
не должны появляться. Дата не должна изменяться после heartbeat, изменения
псевдонима или назначения организации. Клиент старой версии должен продолжать
работать с дополнительным полем.
