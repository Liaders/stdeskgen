Вкладка «Коллеги»
================

В конструкторе: «Оформление» → настройка интерфейса → «Вкладка „Коллеги“».
В JSON-профиле: `"colleagues": true`. Поддерживается Flutter-клиент 1.5.0
для Windows x64, Linux и macOS. Windows x86 использует Sciter.

Вкладка добавляется последней. Слева — пользователи из существующего ответа
сервера, включая текущего пользователя, если сервер его возвращает.
Справа — только возвращённые сервером устройства выбранного пользователя.
Если пользователь не выбран, показаны устройства всех пользователей списка.
Группы устройств здесь не отображаются. Поиск и выбор пользователя независимы
от «Доступных устройств». Псевдонимы и контекстное меню используют тот же
механизм; при включённом изменении ширины вкладка сохраняет собственную ширину.

Сервер может возвращать пользователей из других групп при дополнительных
правах доступа. Членство в группах эта вкладка не определяет и не фильтрует.
Изменения CortenDesk и дополнительные серверные разрешения не нужны.

Поверхность изменений: адаптер добавляет отдельный модуль интерфейса,
шестой элемент в PeerTabModel, точку подключения и обновление/ограничение
удаления в PeerTabPage, русский перевод. Модель прав, запросы, исходная
вкладка и обработчики карточек остаются существующими. Без `colleagues: true`
эти изменения к исходникам не применяются. Старые настройки пяти вкладок
сохраняются, новая вкладка дописывается в конец.
